## What is currently implemented

- The app is a browser/PWA Markdown editor with CodeMirror, project sections,
  images, OPFS storage, optional local-directory storage, live preview, and
  isolated browser-print PDF Preview.
- The shell uses `project-panel`, `task-panel`, and `shared-panel`. The task
  explorer exposes New Container and New Section File actions, and image rows
  can insert Markdown at the editor cursor.
- Preview has a continuous incremental-render lane and an isolated paginated
  lane. The latter uses cancellable iframe pagination and a committed DOM index
  for revision-aware source navigation.
- TOC and special-heading CSS is generated by
  `src/preview/css/document-features-css.ts` and reused by live and paginated
  output. Image alignment preserves asymmetric vertical margins for left,
  center, and right alignment.
- UI tokens and button variants have a shared CSS contract checked by
  `npm run check:styles`; icon markup is centralized in the UI component
  helpers.

## Removed: linked scrolling

`src/preview/navigation/LinkedScrollController.ts` and `LinkedScrollPanes.ts`
were standalone, tested utilities that no production code ever constructed.
They were deleted on 2026-10-15. Do not document linked scrolling as a
product feature; if it is wanted later, it needs a fresh implementation with
browser coverage.

## Safe continuation order

1. Inspect `git status` and preserve the existing in-progress source changes.
2. If continuing the UI refactor, run `npm run check:styles`, `npm run typecheck`,
   and focused tests after each boundary change.
3. If integrating linked scrolling, add application wiring and browser smoke
   coverage first; then update the live-preview and navigation docs.
4. Before release work, run the omitted checks explicitly:
   `npm run check:bundle` and `npm run test:pagedjs-patch`, then the full
   `npm run release:prep` gate.

## Documentation maintenance rule

`docs/DOCUMENTATION_MAP.md` is the source map, not a promise that every planned
page exists. Mark absent guides as planned, and only describe behavior as
shipped when a current source path and regression test or smoke fixture support
the claim.
